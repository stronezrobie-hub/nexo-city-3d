# NEXO LIFE RP

Autorska gra przeglądarkowa 3D w stylu life roleplay, z proceduralnym światem wygenerowanym wyłącznie z kodu.

## Uruchomienie

Gra jest statyczną stroną HTML + Three.js, bez budowania ani modelowania. Otwórz `index.html` przez serwer HTTP (np. `python -m http.server 8080`) i przejdź na `http://localhost:8080`.

## Sterowanie

WASD / strzałki: ruch; E: interakcja; F: telefon; Shift: bieg; C: kamera; P: pauza. Na telefonie dostępne są przyciski ekranowe.

## Założenia

- Grafika i modele: proceduralne bryły 3D.
- Bez tekstur i gotowych assetów 3D.
- Postępy zapisywane lokalnie w przeglądarce.
- Tryb jednoosobowy w wersji alpha; multiplayer wymaga osobnego serwera.
